# Новый набор обращений

new_requests.csv — 120 синтетических обращений, составленных для ручного запуска аудита. Это учебные примеры, а не реальные сообщения клиентов и не независимый тест качества.

Формат: id,text,label; UTF-8 с BOM для удобного открытия в Excel. Используется таксономия 1.1.0-kp2. Все ID и тексты новые относительно остальных CSV в data.

- 100 обращений с одной определенной темой: по 20 на каждый класс.
- Из них у 25 намеренно неверная исходная метка: по 5 на каждый истинный класс.
- 10 обращений с двумя независимыми проблемами.
- 10 обращений без достаточного контекста либо вне таксономии.

Есть технические ошибки конкретной операции, отрицания, решенные проблемы, различия оплаты и возврата, жалобы на доставку и явные просьбы отмены. Исходные метки перемешаны по строкам; порядок классов не кодируется в ID.

Ожидаемые решения находятся отдельно в evaluation/new_requests_gold.json и не входят во входной CSV. Для 75 строк ожидается keep, для 25 — change, для 20 — review. Эталоны синтетические, составлены по определениям классов и не прошли независимую разметку. Существующий CLI evaluate использует dev/test и автоматически этот набор не оценивает.

Чтобы проверить набор, вручную выберите new_requests.csv в интерфейсе и запустите аудит. Создание файла не запускает обработку и не обращается к API.
