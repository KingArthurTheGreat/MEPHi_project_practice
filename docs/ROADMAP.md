# Дорожная карта и смена темы

КП1 посвящен доказательному поиску по учебным материалам. По решению пользователя для КП2 выбрана тема «Метка под вопросом»: аудит разметки обращений. Изменение не маскируется под развитие прежнего RAG. Согласование темы с преподавателем нужно подтвердить; свежая проверка реестра других команд не проводилась.

Причина нового масштаба: узкий проверяемый объект — подозрительная метка, одна область данных, пять содержательных агентных ролей и измеримый бюджет ручной проверки. Связь с курсом сохраняется через LLM, агентные решения, инструменты, наблюдаемость и оценку.

## Целевые метрики финала — гипотезы

Цель: больше реальных ошибочных меток в первых 20 проверках, чем у одиночного LLM и случайной очереди при сопоставимом расходе API. Ориентир precision@20 именно по ошибкам ≥0,80 применим только к реальному набору с достаточным числом ошибок. Если ошибок меньше 16, такой порог математически недостижим и должен быть пересогласован.

Дополнительно: доля ложных предложений изменить чистую метку ≤5%; корректность экспортированных ручных изменений 100%; стоимость на 100 обращений и медиана/p95 времени. Уверенность и расхождения разметчиков анализируются отдельно. Доверительные интервалы считаются по семействам текстов, а не по зависимым парафразам как независимым наблюдениям.
