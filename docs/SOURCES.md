## Официальная документация, проверена 05.11.2026

- [Chat Completions: создание ответа](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create). Использован формат messages, JSON mode и лимит ответа; конкретная модель зависит от доступного аккаунта.
- [Ollama: OpenAI compatibility](https://docs.ollama.com/api/openai-compatibility). Поддерживается совместимый локальный endpoint; для него указан `max_tokens`, поскольку это документированный параметр.
- [Label Studio: ML integration](https://labelstud.io/guide/ml.html). Аналог для интеграции ML-предсказаний в разметку и ручную проверку.
- [cleanlab Datalab: аудит текстовых данных](https://docs.cleanlab.ai/stable/tutorials/datalab/text.html). Прямой аналог поиска label issues, выбросов и близких дубликатов; не заявляется отсутствие у него функций контроля качества.

Фокус проекта — русскоязычная инструкция, явные роли проверяющих, основания решений и очередь с обратной связью. Коммерческое преимущество перед аналогами не измерялось.
